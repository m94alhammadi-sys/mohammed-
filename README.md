# 🗞️ المستشار السياسي على واتساب

وكيل ذكاء اصطناعي تكلّمه على واتساب فيرد عليك كمحلل سياسي كبير: يبحث في الإنترنت لحظياً، يسحب أحدث العناوين من وكالات الأنباء، يقرأ الروابط اللي ترسلها، ويرد بتحليل مسنود بمصادر وتواريخ.

مبني على **Claude (نموذج `claude-opus-5`)** مع أدوات البحث في الإنترنت، ويشتغل عبر **WhatsApp Cloud API** من Meta أو عبر **Twilio**.

---

## المميزات

| الميزة | الوصف |
|---|---|
| 🔎 بحث حي في الإنترنت | يستخدم أداة `web_search` لكل سؤال عن حدث جارٍ، ولا يعتمد على ذاكرته |
| 🔗 قراءة الروابط | ترسل له رابط خبر أو تقرير فيفتحه ويحلله (`web_fetch`) |
| 📰 عناوين مباشرة | أداة `latest_headlines` تسحب من الجزيرة، BBC، العربية، فرانس24، DW، الأمم المتحدة، الغارديان وغيرها |
| 🧠 تحليل عميق | تفكير تكيّفي (adaptive thinking) بعمق قابل للضبط، ومنهج تحليل: الفاعلون → المصالح → السيناريوهات → مؤشرات المتابعة |
| 📅 موجز يومي | موجز سياسي مجدول يوصلك تلقائياً كل صباح |
| 🖼️ تحليل الصور | ترسل صورة خبر أو لقطة شاشة فيقرأها ويعلّق عليها |
| 🗣️ لهجتك | يرد بنفس لغة ولهجة المستخدم (عربي خليجي أو فصحى أو إنجليزي) |
| 🔐 خاص بك | قائمة أرقام مسموح لها فقط + تحقق من توقيع الويبهوك + حد للرسائل بالساعة |
| 💾 ذاكرة محادثة | يتذكر سياق النقاش، وتقدر تمسحه بكلمة "جديد" |

## التشغيل السريع

```bash
git clone <رابط المستودع>
cd mohammed-
npm install
cp .env.example .env
```

افتح `.env` وحط `ANTHROPIC_API_KEY` على الأقل، ثم جرّب الوكيل من الطرفية قبل ربط واتساب:

```bash
npm run chat      # محادثة تجريبية في الطرفية
npm run brief     # يطبع الموجز اليومي
npm test          # 62 اختباراً للوحدات والمسار الكامل
```

لما تتأكد إن الردود تعجبك، اربط واتساب:

```bash
npm start         # يشغّل الخادم على المنفذ 3000
```

## ربط واتساب عبر WhatsApp Cloud API (الموصى به)

1. **أنشئ تطبيقاً** في [developers.facebook.com](https://developers.facebook.com) → *My Apps* → *Create App* → نوع **Business**.
2. أضف منتج **WhatsApp** للتطبيق. راح يعطيك رقم اختبار مجاني و**Phone number ID**.
3. من صفحة *API Setup* انسخ:
   - `META_PHONE_NUMBER_ID`
   - `META_ACCESS_TOKEN` (المؤقت يكفي للتجربة؛ للإنتاج أنشئ *System User Token* دائم)
4. من *App Settings → Basic* انسخ **App Secret** إلى `META_APP_SECRET`.
5. اختر أي نص تبيه واكتبه في `META_VERIFY_TOKEN`.
6. شغّل الخادم واجعله متاحاً على الإنترنت:
   ```bash
   npm start
   npx ngrok http 3000     # في طرفية ثانية
   ```
7. في *WhatsApp → Configuration → Webhook*:
   - **Callback URL**: `https://xxxx.ngrok-free.app/webhook`
   - **Verify token**: نفس `META_VERIFY_TOKEN`
   - اضغط *Verify and Save*، ثم **Subscribe** لحقل `messages`.
8. أضف رقمك في *API Setup → To* كرقم مستقبِل، وأرسل رسالة للرقم التجريبي. راح يرد عليك المستشار.

> ملاحظة: رقم Meta التجريبي يسمح بخمسة أرقام مستقبِلة. للاستخدام الدائم اربط رقمك الخاص عبر *Add phone number*.

## البديل: Twilio

```env
WHATSAPP_PROVIDER=twilio
TWILIO_ACCOUNT_SID=ACxxxx
TWILIO_AUTH_TOKEN=xxxx
TWILIO_WHATSAPP_FROM=+14155238886
TWILIO_WEBHOOK_URL=https://your-domain.com/webhook
```

في لوحة Twilio: *Messaging → Try it out → WhatsApp Sandbox* → حط رابط الويبهوك `https://.../webhook` بطريقة `POST`. انضم للساندبوكس من جوالك بالكلمة اللي يعطيك إياها، وبعدها كلّم الرقم عادي.

## النشر على خادم دائم

**Docker:**
```bash
docker build -t political-agent .
docker run -d --env-file .env -p 3000:3000 -v $(pwd)/data:/app/data --name agent political-agent
```

**VPS مع pm2:**
```bash
npm install -g pm2
pm2 start src/index.js --name political-agent
pm2 save && pm2 startup
```

**Railway / Render / Fly.io:** ارفع المستودع، حط متغيرات البيئة من لوحة المنصة، وخلّ أمر التشغيل `npm start`. بعدها حدّث رابط الويبهوك في Meta ليشير لدومين المنصة.

بعد النشر تحقق من: `https://your-domain.com/health`

## الإعدادات المهمة

| المتغير | الافتراضي | الوظيفة |
|---|---|---|
| `ANTHROPIC_MODEL` | `claude-opus-5` | النموذج. للتوفير: `claude-sonnet-5` |
| `ANTHROPIC_EFFORT` | `high` | عمق التفكير: `low` … `max` |
| `ALLOWED_NUMBERS` | فارغ | أرقام مسموح لها فقط. **اضبطه دائماً في الإنتاج** |
| `MESSAGES_PER_HOUR` | `30` | حد الرسائل لكل رقم بالساعة |
| `BRIEFING_CRON` | `0 7 * * *` | موعد الموجز اليومي |
| `BRIEFING_TIMEZONE` | `Asia/Dubai` | المنطقة الزمنية للجدولة |
| `MAX_WEB_SEARCHES` | `8` | سقف عمليات البحث لكل سؤال |
| `HISTORY_TURNS` | `20` | عدد الأدوار المحفوظة في السياق |
| `EXTRA_FEEDS` | فارغ | مصادر إضافية: `الاسم\|الرابط\|ar` |

## التخصيص

- **شخصية المحلل وأسلوبه**: `src/ai/systemPrompt.js` — عدّل `SYSTEM_PROMPT` لتغيير التخصص (مثلاً التركيز على ملف بعينه) أو طول الردود. شكل الموجز اليومي في `BRIEFING_PROMPT`.
- **المصادر الإخبارية**: `src/news/sources.js` — أضف أو احذف تغذيات RSS.
- **الأوامر**: `src/commands.js` — أضف كلمات مفتاحية أو أوامر جديدة.

## الأمان والخصوصية

- كل رسالة واردة من Meta يُتحقق من توقيعها `X-Hub-Signature-256` قبل معالجتها، وطلبات Twilio يُتحقق من توقيعها كذلك.
- `ALLOWED_NUMBERS` يمنع أي رقم غريب من استهلاك حسابك.
- المحادثات تُحفظ محلياً في `data/sessions.json` فقط، ولا تُرسل لأي جهة غير واجهة Claude.
- أرقام الهواتف تُخفى جزئياً في السجلات.
- لا ترفع ملف `.env` إلى GitHub (مستثنى في `.gitignore`).

## استكشاف الأخطاء

| العطل | السبب المرجّح |
|---|---|
| فشل التحقق من الويبهوك | `META_VERIFY_TOKEN` مختلف بين `.env` ولوحة Meta |
| الرسائل توصل ولا يرد | لم تشترك في حقل `messages`، أو الرقم خارج `ALLOWED_NUMBERS` |
| رد 403 في السجل | `META_APP_SECRET` خاطئ أو ناقص |
| خطأ 401 من Claude | `ANTHROPIC_API_KEY` غير صحيح أو منتهي |
| لا تظهر عناوين من المصادر | الشبكة تحجب مواقع الأخبار — البحث في الإنترنت يظل شغالاً |
| رفض معامل غير مدعوم | الوكيل يتراجع تلقائياً ويعيد المحاولة، وتظهر ملاحظة في السجل |
