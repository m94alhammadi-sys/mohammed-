# مجلس القرار — تطبيق دردشة بمنظومة وكلاء مستقلين

تطبيق بواجهة شبيهة بالواتساب، لكن جهات الاتصال فيه **وكلاء ذكاء اصطناعي
متخصصون**. تكتب موضوعاً في «غرفة القرار»، فيبحث كل وكيل في اختصاصه
بالتوازي، ثم يرفع الجميع تقاريرهم إلى وكيل تنسيقي محايد يربط الخيوط
ويعيد إليك **تقريراً تنفيذياً** بقرار وثقة ومخاطر وخيارات تنفيذ وشروط
إبطال.

المستخدم هو صاحب القرار الأعلى. النظام يرفع جودة المعلومة ويكشف
تضاربها ويعلن حدوده — ولا يقرر نيابةً عنك.

---

## الوكلاء

| الوكيل | الاختصاص | أهم ما يرصده |
|---|---|---|
| **بوالعلوم** | مشاعر ومنصات التواصل | الزخم، التوزيع العاطفي، المؤثرون، الشائعات، علامات التلاعب |
| **المحلل السياسي** | الجيوسياسة | القرارات الحكومية، العقوبات، النزاعات، قنوات الانتقال للاقتصاد |
| **المحلل الاقتصادي** | الاقتصاد الكلي | التضخم، الفائدة، البنوك المركزية، السيولة، منحنى العائد |
| **غرفة العاجل** | الأحداث الطارئة | ما هو غير مجدول، بدرجة إلحاح معايرة وحالة تأكيد معلنة |
| **التاجر** | تدفقات السوق | الحيتان، الصفقات الكتلية، المطلعون، الدعم والمقاومة، التجميع والتصريف |
| **الوكيل التنسيقي** | التركيب والقرار | المطابقة التبادلية، حسم التضارب، تحييد الضجيج، التقرير التنفيذي |

## ثلاث قواعد بنيوية

هذه ليست نصائح في برومبت، بل قيود منفّذة في الكود ومغطاة باختبارات:

**١. المتخصص يرصد، والتنسيقي وحده يقرر.**
لا يوجد حقل توصية في `AgentReport` أصلاً، والتنسيقي لا يملك أي موصل
بيانات خارجي — مصدره الوحيد تقارير الوكلاء، فهو مُركِّب لا مصدر.

**٢. لا ادعاء بلا دليل.**
كل إشارة تحيل إلى فهرس في قائمة الأدلة. الإحالة إلى دليل غير موجود
تُحذف تلقائياً، والإشارة بلا دليل تُنقل قسراً إلى `unverified_claims`.

**٣. الأرقام الحاسمة تُحسب ولا تُكتب.**
الثقة ودرجة المخاطرة والتضارب تُحسب في `backend/synthesis.py` بدوال
صرفة قابلة للاختبار، ثم تُفرض على مخرج النموذج. النموذج يكتب التحليل
داخل هذه الأرقام، لا العكس.

نتيجة مباشرة لذلك: **إذا انقطعت المصادر، يقول النظام «لا قرار»** بدل أن
يخترع تحليلاً. جرّبه بنفسك بضبط `OFFLINE_DEMO=1`.

### كيف تُحسب الثقة

```
ابدأ من أضعف حلقة = min(ثقة كل الوكلاء)   ← لا متوسط: المتوسط يخفي الأعمى
  + تأكيد مستقل من وكلاء متعددين          (حتى +0.20)
  + تقاطع المصادر                          (حتى +0.10)
  − التضارب غير المحسوم                    (حتى −0.25)
  − فجوات البيانات المعلنة                 (حتى −0.12)
  − الادعاءات غير المؤكدة                  (حتى −0.08)
  ⇒ سقف 0.60 إن عمل أي وكيل بلا مصادر حية
```

وتظهر السلسلة كاملة في التقرير:

```
سلسلة حساب الثقة: البداية من أضعف حلقة: 0.41 ← تقاطع مصادر بنسبة 100%: +0.10
← 2 تضارب غير محسوم: -0.07 ← 4 فجوة بيانات معلنة: -0.08 ← الثقة النهائية: 0.35
```

## التشغيل

```bash
git clone <repo> && cd mohammed-
cp .env.example .env          # ثم أضف ANTHROPIC_API_KEY
./run.sh                      # أو: python3 -m uvicorn backend.main:app --reload
```

افتح <http://127.0.0.1:8000>.

**بلا مفتاح API؟** التطبيق يعمل ويعرض الواجهة ويعلن بوضوح أنه في وضع
منقطع. لرؤية شكل دورة مكتملة:

```bash
python3 scripts/demo_seed.py   # بيانات توضيحية موسومة صراحةً
```

**الاختبارات:**

```bash
python3 -m pytest -q           # 122 اختباراً، بلا أي نداء شبكة
```

## بنية المشروع

```
backend/
  main.py           FastAPI: REST + WebSocket + بث الحالة
  orchestrator.py   التوزيع المتوازي والالتقاء والمهل الزمنية
  synthesis.py      محرك التركيب الحتمي (ثقة · تضارب · مخاطرة · اتجاه)
  prompts.py        برومبتات النظام لكل وكيل
  schemas.py        عقود A2A: Envelope · AgentReport · ChiefDecision
  bus.py            ناقل الرسائل + سجل التدقيق
  llm.py            طبقة Claude: بحث ← هيكلة، مع تدهور معلن عند الفشل
  memory.py         ذاكرة استرجاعية: SQLite FTS5 + محوّل Qdrant
  store.py          تخزين المحادثات والقرارات
  formatting.py     تحويل التقارير إلى نص دردشة عربي
  agents/           base.py (المتخصص) · chief.py (التنسيقي)
  tools/            موصلات: news · market · social · macro + سجل الصلاحيات
frontend/           واجهة RTL بلا خطوة بناء
docs/               المستندات الثلاثة المطلوبة
scripts/            demo_seed.py · export_prompts.py
tests/              122 اختباراً
```

## الواجهة البرمجية

| النقطة | الوظيفة |
|---|---|
| `POST /api/cycle` | تشغيل دورة تحليل كاملة (تُبثّ نتائجها عبر WebSocket) |
| `POST /api/chat` | دردشة مباشرة مع وكيل واحد |
| `GET /api/chats` | قائمة الدردشات |
| `GET /api/decisions/{id}` | القرار كاملاً بصيغة JSON |
| `GET /api/trace/{correlation_id}` | **سجل التدقيق**: كل رسائل الدورة |
| `GET /api/memory?q=` | بحث في ذاكرة الوكلاء |
| `WS /ws` | بث الرسائل ومؤشرات «يبحث الآن» |

## حدود النظام

- **ليس نصيحة استثمارية.** نظام دعم قرار: يعرض خيارات ومخاطر وشروط
  إبطال، والقرار لك.
- **لا يتنبأ بالأسواق.** يرصد ويربط ويعلن درجة ثقته وحدودها.
- **جودته من جودة مصادره.** بلا مفاتيح مصادر، يعمل على ما هو متاح
  ويُعلن ما عجز عنه في `data_gaps`.
- **لا كشط مخالف.** المنفّذ: خلاصات RSS منشورة، وواجهات JSON عامة،
  وواجهات رسمية بمفاتيح.
