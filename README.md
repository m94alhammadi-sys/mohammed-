# 📊 المستشار الاقتصادي — وكيل خبير على واتساب

وكيل ذكاء اصطناعي يتكلم معك على واتساب كأنه خبير اقتصادي كبير: يحلل الأسواق، يقرأ
الأخبار والسياسة لحظة بلحظة من الإنترنت، **ويبادر هو بتنبيهك** لما تصير فرصة أو حدث
يستاهل انتباهك.

---

## وش يقدر يسوي؟

| المجال | التفاصيل |
|---|---|
| **الفوركس** | كل الأزواج الرئيسية والثانوية، مؤشر الدولار، فروقات الفائدة |
| **الأسهم الإماراتية** | 48 شركة من سوق أبوظبي (ADX) وسوق دبي (DFM) بأسمائها العربية |
| **الأسهم العالمية** | وول ستريت، أوروبا، آسيا — أي رمز مدعوم |
| **السلع** | الذهب، الفضة، النفط (WTI وبرنت)، الغاز، النحاس |
| **العملات الرقمية** | بيتكوين، إيثيريوم، وغيرها |
| **التحليل الفني** | RSI، ماكد، بولنجر، ADX، ATR، ستوكاستيك، فيبوناتشي، الدعوم والمقاومات، الانفراجات |
| **الأخبار والسياسة** | بحث حي في الإنترنت + مصادر RSS عربية وعالمية |
| **المفكرة الاقتصادية** | قرارات الفائدة، التضخم، الوظائف — قبل وبعد صدورها |
| **إدارة المخاطر** | حاسبة حجم المركز، وقف الخسارة، نسبة المخاطرة للعائد |

### يبادر بنفسه — ما تحتاج تسأله

- 🔔 **تنبيهات الفرص** — يمسح قائمة متابعتك كل ربع ساعة، وإذا لقى إشارة قوية
  يتحقق منها بالأخبار أولاً، وما ينبهك إلا لو كانت حقيقية.
- 📈 **تنبيهات سعرية** — «نبهني إذا نزل الذهب تحت 3900».
- ☀️ **الموجز الصباحي** — كل يوم عمل قبل فتح السوق.
- 🌙 **ملخص الإغلاق** — كيف أغلقت الأسواق وليش.
- ⚠️ **الصدمات الإخبارية** — يرصد الأخبار عالية التأثير ويقيّم أثرها عليك.
- ⏰ **تذكيرات شخصية** — «ذكرني الساعة 4 أراجع محفظتي».

### أمثلة على المحادثة

```
أنت:      وش رايك في سهم إعمار؟
المستشار: *إعمار العقارية (EMAAR.DU)* — 8.42 درهم 📈
          الاتجاه صاعد فوق EMA50، ADX عند 31 يأكد قوته.
          RSI 58 — فيه مجال للصعود بدون تشبع.
          ...

أنت:      تابع لي الذهب ونبهني إذا نزل تحت 3900
المستشار: ضفت الذهب لقائمة متابعتك ✅ وسأنبهك إذا نزل تحت 3900.

أنت:      شنو أهم شي بيأثر على السوق هالأسبوع؟
المستشار: [يبحث في الإنترنت ويقرأ المفكرة الاقتصادية ثم يجاوب]
```

## ⚡ التشغيل السريع

### 1) المتطلبات

- Python 3.11 أو أحدث
- مفتاح **Anthropic API** من [console.anthropic.com](https://console.anthropic.com)
- حساب **WhatsApp Business** (مجاني) أو حساب Twilio

### 2) التثبيت

```bash
git clone <رابط-المستودع>
cd mohammed-
cp .env.example .env
# افتح .env وعبّي المفاتيح
./run.sh
```

أو بـ Docker:

```bash
cp .env.example .env     # عبّي المفاتيح
docker compose up -d
docker compose logs -f
```

### 3) تأكد أن كل شي مضبوط

```bash
python -m app.doctor
```

أداة الفحص تجرّب مفتاح Claude والاتصال بواتساب ومصدر الأسعار، وتقول لك
بالضبط وش ناقص وكيف تصلّحه.

### 4) ربط واتساب

📘 **الدليل الكامل خطوة بخطوة: [`docs/ربط-واتساب.md`](docs/ربط-واتساب.md)**

باختصار:

#### الخيار أ — Meta WhatsApp Cloud API (موصى به، رسمي ومجاني للبداية)

1. ادخل [developers.facebook.com](https://developers.facebook.com) وأنشئ تطبيقاً من نوع **Business**.
2. أضف منتج **WhatsApp** → ستحصل على:
   - `META_PHONE_NUMBER_ID`
   - `META_ACCESS_TOKEN` (مؤقت للتجربة — استبدله بتوكن دائم للإنتاج)
3. اختر `META_VERIFY_TOKEN` (أي نص عشوائي من عندك) وضعه في `.env`.
4. شغّل الخادم واجعله متاحاً من الإنترنت:
   ```bash
   ./run.sh
   # في نافذة ثانية
   ngrok http 8000
   ```
5. في إعدادات WhatsApp → **Configuration → Webhook**:
   - **Callback URL**: `https://xxxx.ngrok-free.app/webhook/whatsapp`
   - **Verify Token**: نفس `META_VERIFY_TOKEN`
   - اشترك في حقل **messages**.
6. أرسل رسالة من رقمك للرقم التجريبي وجرّب.

> ⚠️ **مهم — نافذة الـ 24 ساعة**: واتساب يمنع إرسال رسائل حرة بعد مرور 24 ساعة
> على آخر رسالة منك. الوكيل يتحول تلقائياً لقالب معتمد خارج النافذة. اعتمد
> قالباً باسم `market_alert` (متغير نصي واحد `{{1}}`) من
> **WhatsApp Manager → Message Templates** حتى تصلك التنبيهات دائماً.

#### الخيار ب — Twilio (أسرع للتجربة)

```env
WHATSAPP_PROVIDER=twilio
TWILIO_ACCOUNT_SID=ACxxxx
TWILIO_AUTH_TOKEN=xxxx
TWILIO_WHATSAPP_FROM=whatsapp:+14155238886
```

في [Twilio Console](https://console.twilio.com) → WhatsApp Sandbox، اضبط
**When a message comes in** على `https://xxxx.ngrok-free.app/webhook/whatsapp`.

## ⚙️ الإعدادات المهمة

| المتغير | الشرح | الافتراضي |
|---|---|---|
| `ALLOWED_NUMBERS` | الأرقام المصرّح لها فقط. **اضبطه دائماً** — بدونه أي رقم يقدر يستخدم مفتاحك | فارغ = الجميع |
| `OWNER_NUMBER` | رقمك — يستقبل الموجزات ويُراقب معه المؤشرات الأساسية | — |
| `SCAN_INTERVAL_MINUTES` | كل كم دقيقة يمسح السوق | 15 |
| `ALERT_MIN_SCORE` | أقل درجة قوة (0-100) قبل التنبيه. ارفعه لتقليل الإزعاج | 68 |
| `ALERT_COOLDOWN_HOURS` | لا يكرر نفس التنبيه قبل هذه المدة | 6 |
| `MAX_ALERTS_PER_DAY` | سقف التنبيهات اليومية | 12 |
| `MORNING_BRIEF_TIME` | وقت الموجز الصباحي | 07:30 |
| `CLAUDE_EFFORT` | عمق التفكير: `low` أرخص، `max` أدق | high |

## 🏗️ كيف يشتغل؟

```
رسالة واتساب
     │
     ▼
 webhook (FastAPI) ──► فحص الصلاحية ──► فتح نافذة الـ 24 ساعة
     │
     ▼
  brain.py — حلقة الأدوات مع Claude Opus 5
     │
     ├─ أدوات السوق  : أسعار، تحليل فني، مقارنة، ارتباط، أكبر الرابحين
     ├─ أدوات المعرفة: بحث في الإنترنت (web_search)، أخبار RSS، مفكرة اقتصادية
     └─ أدوات الإدارة: قائمة متابعة، تنبيهات سعرية، تذكيرات، ذاكرة دائمة
     │
     ▼
  الرد ──► تقسيم تلقائي + تنسيق واتساب ──► المستخدم


  ⏱️ بالتوازي: scheduler.py
     ├─ كل دقيقة    : التذكيرات
     ├─ كل 5 دقائق  : التنبيهات السعرية
     ├─ كل 15 دقيقة : مسح الفرص ──► تحليل فني ──► تحقق بالنموذج ──► تنبيه
     ├─ كل 30 دقيقة : رصد الصدمات الإخبارية
     └─ يومياً      : الموجز الصباحي وملخص الإغلاق
```

### كيف يقرر أن هناك «فرصة»؟

1. **المرحلة الكمّية** — يحسب عشر مجموعات إشارات (اتجاه، زخم، تقلب، حجم، مستويات)
   ويحوّلها لدرجة من 0 إلى 100، حيث 50 محايد. الثقة تتناسب مع عدد الإشارات
   المتفقة، وإشارات الارتداد (مثل التشبع البيعي) يُخفَّض وزنها تلقائياً داخل
   اتجاه مؤكد — لأن «تشبع بيعي» وسط انهيار ليس إشارة شراء.
2. **مرحلة التحقق** — لا يُرسل شيء قبل أن يراجع النموذج الإشارة مع الأخبار
   والمفكرة الاقتصادية. إذا حكم أنها ضجيج يردّ بـ `تجاهل` ولا تصلك رسالة.
3. **مرحلة الكبح** — فترة تهدئة لكل رمز، وسقف يومي للتنبيهات.

هذا الوكيل أداة تحليلية تعليمية وليس مستشاراً مالياً مرخّصاً. لا يقدّم توصيات
