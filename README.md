# راصد — مستشار مالي واقتصادي ذكي 📈

بوت تيليجرام (مع واجهة واتساب اختيارية) يعمل بـ **Claude Opus 5**، يبحث في الإنترنت لحظياً
قبل أي رقم أو توصية، ويعطي تحليلاً مربوطاً بملف المخاطر الخاص بك ومحفظتك.

**الأسواق المغطاة:** الأسواق العالمية (أمريكا وأوروبا) · السوق الإماراتي (ADX و DFM) ·
الذهب والسلع والعملات · العملات الرقمية.

> ⚠️ **تنويه:** هذا تحليل تعليمي وليس استشارة مالية مرخّصة. القرار النهائي ومسؤوليته عليك،
> والأسواق لا تُضمن نتائجها.

## التشغيل في ٥ دقائق

### ١. المتطلبات
- Python 3.11 أو أحدث.
- مفتاح Claude من [console.anthropic.com](https://console.anthropic.com) (مع رصيد).
- توكن بوت تيليجرام: افتح [@BotFather](https://t.me/BotFather) → `/newbot` → انسخ التوكن.

### ٢. التثبيت
```bash
git clone <رابط-المستودع> && cd mohammed-
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

### ٣. الإعداد
```bash
cp .env.example .env
```
ثم افتح `.env` واملأ المفتاحين على الأقل:
```
ANTHROPIC_API_KEY=sk-ant-...
TELEGRAM_BOT_TOKEN=123456:ABC...
```

### ٤. التشغيل
```bash
python run_telegram.py
```
افتح بوتك في تيليجرام واكتب `/start`. خلاص — شغّال.

### ٥. (مهم) اجعله خاصاً بك
البوت مفتوح للجميع افتراضياً. أرسل `/start` وسيعرض لك معرّفك إن فعّلت القيد، أو استخدم
[@userinfobot](https://t.me/userinfobot) لمعرفة رقمك، ثم ضعه في `.env`:
```
ADVISOR_ALLOWED_USER_IDS=123456789
```
**بدون هذا، أي شخص يجد بوتك يستهلك من رصيد مفتاحك.**

## التشغيل الدائم على خادم

```bash
# systemd — مثال
sudo tee /etc/systemd/system/rased.service <<'EOF'
[Unit]
Description=Rased financial advisor bot
After=network-online.target

[Service]
WorkingDirectory=/opt/rased
ExecStart=/opt/rased/.venv/bin/python run_telegram.py
Restart=always
RestartSec=10
User=rased

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl enable --now rased
```
البوت يستخدم long-polling: **لا يحتاج دومين ولا IP عام ولا شهادة SSL.**

## واتساب (اختياري)

واتساب لا يسمح ببوتات شخصية بسهولة — يحتاج حساب Meta Business ورقماً معتمداً ورابط HTTPS عام.
لو توفّر لديك ذلك:

```bash
pip install fastapi uvicorn
# املأ WHATSAPP_TOKEN و WHATSAPP_PHONE_NUMBER_ID و WHATSAPP_VERIFY_TOKEN في .env
python run_whatsapp.py
```
ثم في لوحة Meta: اربط الـ Webhook بالرابط `https://نطاقك/webhook` وضع نفس `VERIFY_TOKEN`.

نفس نواة المستشار تخدم القناتين، والملف الشخصي والمحفظة مشتركان.

## كيف يشتغل؟

```
رسالة المستخدم
     │
     ├─► advisor/storage.py    ← ملف المخاطر + المحفظة + قائمة المتابعة + ذاكرة المحادثة (SQLite)
     ├─► advisor/market_data.py ← أسعار مباشرة: stooq (مؤشرات/ذهب/نفط/عملات)
     │                            coingecko (رقمية) · yahoo (أسهم إماراتية)
     └─► advisor/brain.py      ← Claude Opus 5 + أداتا web_search و web_fetch
                                  (بحث حيّ في الإنترنت على خوادم Anthropic)
                                          │
                                   رد عربي منظّم + مصادر + تنويه
```

**قرارات تصميمية مقصودة:**
- **الاتصال بالإنترنت** عبر أدوات الخادم من Anthropic — لا تحتاج اشتراكاً في أي مزوّد أخبار.
- **الأسعار المباشرة** تُحقن في سياق النموذج ليبني عليها بدل أن يخمّن؛ وأي مصدر يفشل
  يُبلَّغ النموذج صراحةً بأنه غير متاح ليعوّضه بالبحث.
- **التخزين المؤقت للنص النظامي** (`cache_control`) يخفّض كلفة كل رسالة بعد الأولى.
- **التفكير التكيّفي** (`thinking: adaptive`) مع `effort=high` — تحليل أعمق للأسئلة المعقدة.
- **الرجوع التلقائي** لموديل بديل إذا رفض الأساسي الطلب، ويُطفأ ذاتياً إن لم يدعمه حسابك.
- **معالجة `pause_turn`** حتى لا ينقطع الرد في منتصف بحث طويل.

## الكلفة

الكلفة على استهلاك Claude فقط (لا اشتراكات أخرى). بأسعار Opus 5 الحالية
($5 لكل مليون توكن إدخال / $25 إخراج) الرسالة الواحدة مع بحث تقع غالباً في نطاق
**$0.05–0.25**، والإحاطة اليومية أعلى قليلاً لأنها تبحث أكثر.

للتوفير: بدّل الموديل في `.env`:
```
ADVISOR_MODEL=claude-sonnet-5     # أرخص بكثير، جودة أقل في التحليل المركّب
ADVISOR_EFFORT=medium
```

## حدود معروفة (اقرأها)

1. **رموز السوق الإماراتي في `advisor/market_data.py` (`UAE_UNIVERSE`) تحتاج تحقّقاً منك.**
   بيئة التطوير التي بُني فيها المشروع تحجب المواقع الخارجية، فلم يُختبر جلبها حياً.
   شغّل `/market` أول مرة: إن ظهرت أسعار الأسهم الإماراتية فالرموز صحيحة، وإلا عدّلها
   (Yahoo Finance يستخدم لاحقة `.AE` لأسهم دبي وأبوظبي).
2. **مؤشرا ADX و DFM العامان** ليسا ضمن المصادر المجانية المباشرة — المستشار يجلب
   مستوياتهما بالبحث في الإنترنت ويذكر المصدر.
3. **المصادر المجانية قد تتغير أو تُحجب.** التصميم يتحمّل ذلك: أي مصدر يسقط يُستبدل
   بالبحث الحي، لكن الأسعار في `/market` قد تنقص.
4. **ليس نظام تداول آلي.** لا ينفّذ أوامر ولا يتصل بوسيط، ولا يراقب الأسعار لحظياً
   للتنبيه عند اختراق مستوى (يمكن إضافتها لاحقاً).
5. **لا يعرف أسعار الأمس بدقة تاريخية طويلة** — يعتمد على آخر ١٤ يوماً من كل مصدر.
