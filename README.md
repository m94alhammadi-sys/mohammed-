# Sky Avero — موقع المنتجات والأسعار

موقع ثابت (HTML/CSS/JS) لعرض منتجات حساب [@skyavero](https://www.instagram.com/skyavero/) وأسعارها، مع سلة وطلب مباشر عبر واتساب أو انستقرام.

## تعديل المنتجات والأسعار
كل شيء في ملف `products.js`:
- `STORE`: اسم المتجر، الوصف، حساب الانستقرام، رقم الواتساب، العملة.
- `PRODUCTS`: قائمة المنتجات (الاسم، التصنيف، السعر، السعر قبل الخصم، الصورة، الوصف، الشارة، التوفر).

الصور: ضعها في مجلد `assets/` واكتب المسار مثل `"assets/product1.jpg"`.

## التشغيل
افتح `index.html` في المتصفح، أو انشره مجاناً عبر GitHub Pages (Settings → Pages → Branch).
