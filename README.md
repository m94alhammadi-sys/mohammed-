# 🤖 ايجنت تداول الميم كوينز (Solana + Phantom)

بوت يدور على الميم كوينز اللي عليها زخم في شبكة سولانا، يفحص إذا كانت آمنة، ويشتري ويبيع تلقائياً عن طريق Jupiter، بمحفظة Phantom حقتك.

> ## ⚠️ اقرأ هذا قبل كل شي
> - **الميم كوينز مقامرة عالية المخاطر.** أغلبها تنزل للصفر، وفيها نصب كثير (rug pulls). ما في بوت يضمن ربح، وتقدر تخسر كل المبلغ اللي تحطه.
> - البوت يشتغل افتراضياً في **وضع تجريبي (`DRY_RUN=true`)**: يتداول بفلوس وهمية بس. خله كذا كم يوم وشوف النتايج في `data/trades.csv` قبل لا تحط فلوس حقيقية.
> - **لا تستخدم محفظتك الرئيسية.** سوّ حساب جديد في Phantom للبوت بس، وحط فيه مبلغ صغير تتحمل تخسره.
> - **المفتاح الخاص = فلوسك.** لا ترسله لأي أحد (ولا حتى لي في المحادثة). يتحط بس في ملف `.env` على جهازك، والملف هذا مستثنى من git.

## إيش يسوي البوت

كل دورة (افتراضياً كل 20 ثانية):

1. **يتابع الصفقات المفتوحة**: يحسب قيمتها الحقيقية بـ SOL من Jupiter، ويبيع إذا صار:
   - ربح ≥ `TAKE_PROFIT_PCT` (افتراضي +50%)
   - خسارة ≥ `STOP_LOSS_PCT` (افتراضي -20%)
   - Trailing stop: بعد ما يربح +20%، يبيع إذا نزل 15% من أعلى نقطة
   - مرّ أكثر من `MAX_HOLD_MINUTES`
2. **يدور على عملات جديدة** من DexScreener (المروّجة والجديدة) ويفلترها: السيولة، الفوليوم، عمر العملة، نسبة الشراء للبيع، التغير بالسعر، الـ FDV.
3. **فحوصات أمان قبل الشراء**:
   - المطوّر ما يقدر يطبع توكنات جديدة (mint authority)
   - المطوّر ما يقدر يجمد محفظتك (freeze authority)
   - ما فيها إضافات Token‑2022 خطيرة (ضريبة تحويل، permanent delegate…)
   - تقرير rugcheck.xyz
   - **فحص honeypot**: يتأكد إنه يقدر يبيع قبل لا يشتري، وإن خسارة الشراء+البيع الفوري أقل من 25%
   - تأثير السعر أقل من `MAX_PRICE_IMPACT_PCT`
4. **إدارة المخاطر**: حد أقصى لعدد الصفقات، حد أقصى للمبلغ المعرّض للخطر، رصيد احتياطي للرسوم، و**حد خسارة يومي** يوقف الشراء إذا وصله.

## التشغيل

تحتاج [Node.js 20+](https://nodejs.org).

```bash
git clone <هذا الريبو>
cd mohammed-
npm install
cp .env.example .env
npm start            # يشتغل بالوضع التجريبي
```

أوامر ثانية:

```bash
npm run status       # يعرض الصفقات المفتوحة والأرباح/الخسائر
npm run panic        # يبيع كل الصفقات المفتوحة فوراً
```

`Ctrl+C` يوقف البوت بعد الدورة الحالية (الصفقات المفتوحة تبقى؛ لو تبي تبيعها شغّل `npm run panic`).

## التحويل للتداول الحقيقي

1. في Phantom: **Add / Connect Account → Create New Account** (حساب مخصص للبوت).
2. حوّل له مبلغ صغير من SOL (مثلاً 0.3 SOL).
3. طلّع المفتاح الخاص: **Settings → Manage Accounts → (الحساب الجديد) → Show Private Key**.
4. حطه في `.env`:
   ```
   PRIVATE_KEY=المفتاح_هنا
   DRY_RUN=false
   ```
5. (يُنصح فيه بقوة) استخدم RPC خاص في `RPC_URL` — مثلاً خطة Helius المجانية. الـ RPC العام بطيء ويرفض طلبات كثير.
6. `npm start` — البوت يعطيك 10 ثواني تلغي فيها قبل لا يبدأ.

## الإعدادات

كل الإعدادات في `.env` ومشروحة في `.env.example`. أهمها:

| الإعداد | الافتراضي | المعنى |
|---|---|---|
| `BUY_AMOUNT_SOL` | 0.05 | مبلغ كل صفقة |
| `MAX_OPEN_POSITIONS` | 3 | أقصى عدد صفقات بنفس الوقت |
| `MAX_TOTAL_EXPOSURE_SOL` | 0.2 | أقصى مجموع داخل الصفقات |
| `DAILY_LOSS_LIMIT_SOL` | 0.1 | يوقف الشراء لباقي اليوم إذا خسر هالمبلغ |
| `TAKE_PROFIT_PCT` / `STOP_LOSS_PCT` | 50 / 20 | جني الربح / وقف الخسارة |
| `SLIPPAGE_BPS` | 1500 | 15% انزلاق مسموح |
| `MIN_LIQUIDITY_USD` | 20000 | أقل سيولة مقبولة |
| `MIN_PAIR_AGE_MINUTES` | 30 | يتجنب العملات اللي توها نازلة |
