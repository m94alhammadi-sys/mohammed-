# 📱 كيف تربط الوكيل بواتساب — خطوة بخطوة

> **قبل أي شي**: شغّل أداة الفحص، وهي تقول لك بالضبط وش ناقص عندك:
> ```bash
> python -m app.doctor
> ```

---

## تفهم الصورة أولاً

الوكيل برنامج يشتغل على جهاز أو خادم. واتساب لازم **يوصل له من الإنترنت** عشان
يوصّل له رسائلك. يعني تحتاج ثلاث حلقات:

```
جوالك ──► واتساب ──► رابط عام على الإنترنت ──► الوكيل عندك
```

الحلقة الوسطى (الرابط العام) هي اللي غالباً تسبب الحيرة. عندك حلان:
- **للتجربة**: `ngrok` — يعطيك رابطاً مؤقتاً لجهازك خلال دقيقة.
- **للاستخدام الدائم**: خادم (VPS) أو منصة مثل Railway أو Render.

> ⚠️ **مهم**: التنبيهات الاستباقية والموجز الصباحي تحتاج الوكيل **شغّالاً 24 ساعة**.
> لو شغّلته على لابتوبك وسكّرته، ما تجيك تنبيهات. للاستخدام الجدي لازم خادم.

# الطريق الأول: Twilio — الأسرع للتجربة (10 دقائق)

ما يحتاج توثيق أعمال ولا موافقة قوالب. تجربه اليوم.

### 1) سجّل في Twilio

ادخل [twilio.com/try-twilio](https://www.twilio.com/try-twilio) وأنشئ حساباً مجانياً.

### 2) فعّل صندوق تجربة واتساب

من القائمة الجانبية:
**Messaging ← Try it out ← Send a WhatsApp message**

ستشوف صفحة فيها:
- رقم Twilio، عادةً `+1 415 523 8886`
- كلمة انضمام مثل `join tiger-plant`

**من جوالك**: افتح واتساب، أرسل رسالة للرقم `+1 415 523 8886` نصّها كلمة الانضمام
بالضبط (`join tiger-plant`). بيرد عليك يأكد أنك انضممت.

### 3) خذ مفاتيحك

من [console.twilio.com](https://console.twilio.com) الصفحة الرئيسية:
- **Account SID** — يبدأ بـ `AC`
- **Auth Token** — اضغط لإظهاره

### 4) عبّي ملف `.env`

```env
WHATSAPP_PROVIDER=twilio

TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxx
TWILIO_AUTH_TOKEN=xxxxxxxxxxxxxxxxxxxxxx
TWILIO_WHATSAPP_FROM=whatsapp:+14155238886

ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxx

ALLOWED_NUMBERS=971500000000
OWNER_NUMBER=971500000000
```

> ✏️ بدّل `971500000000` برقمك بالصيغة الدولية **بدون + وبدون أصفار أو مسافات**.
> رقم إماراتي `050 123 4567` يصير `971501234567`.

### 5) شغّل الوكيل

```bash
python -m app.doctor      # تأكد أن كل شي أخضر
./run.sh
```

### 6) افتح الباب للإنترنت

في نافذة طرفية ثانية:

```bash
ngrok http 8000
```

بيطلع لك سطر مثل:
```
Forwarding   https://ab12-cd34.ngrok-free.app -> http://localhost:8000
```
انسخ الرابط اللي يبدأ بـ `https`.

> ما عندك ngrok؟ حمّله من [ngrok.com/download](https://ngrok.com/download)
> (مجاني، يحتاج تسجيل سريع).

### 7) اربط الـ webhook

ارجع لصفحة **Send a WhatsApp message** في Twilio ← تبويب **Sandbox settings**.

في خانة **When a message comes in** ضع:

```
https://ab12-cd34.ngrok-free.app/webhook/whatsapp
```

> ☝️ لا تنسَ `/webhook/whatsapp` في آخر الرابط — هذا أكثر خطأ شائع.

الطريقة: **HTTP POST**. اضغط **Save**.

### 8) جرّب!

من واتساب، أرسل للرقم نفسه: **`بدء`**

المفروض يرد عليك برسالة الترحيب. بعدها جرّب:
> *وش رايك في سهم إعمار؟*

✅ **خلصت.**

> ⏳ صندوق تجربة Twilio ينتهي كل 72 ساعة — تعيد إرسال كلمة `join` وترجع.
> للاستخدام الدائم لازم رقم واتساب مدفوع من Twilio.

# الطريق الثاني: Meta WhatsApp Cloud API — الرسمي والمجاني

أطول شوي (نص ساعة) لكنه الحل الصحيح للاستخدام الدائم، وبرقمك أنت.

### 1) أنشئ تطبيقاً

1. ادخل [developers.facebook.com](https://developers.facebook.com) وسجّل دخولك بفيسبوك.
2. **My Apps ← Create App**
3. اختر نوع **Business** ← اكتب اسماً (مثلاً `المستشار`) ← **Create**

### 2) أضف منتج واتساب

في صفحة التطبيق، دوّر على **WhatsApp** واضغط **Set up**.

ستنتقل لصفحة **API Setup** وفيها كل اللي تحتاجه:

| الحقل في الصفحة | وين يروح في `.env` |
|---|---|
| **Phone number ID** | `META_PHONE_NUMBER_ID` |
| **Temporary access token** | `META_ACCESS_TOKEN` |

### 3) أضف رقمك كمستلم ⚠️

في نفس الصفحة، تحت **To**، اضغط **Manage phone number list** وأضف رقم جوالك.
بيجيك كود تأكيد على واتساب.

> هذي خطوة **إلزامية**. رقم التجربة ما يرسل إلا للأرقام المسجّلة هنا (حتى 5 أرقام).
> أكثر سبب لـ «ما وصلتني رسالة».

### 4) عبّي ملف `.env`

```env
WHATSAPP_PROVIDER=meta

META_ACCESS_TOKEN=EAAxxxxxxxxxxxxxxxxx
META_PHONE_NUMBER_ID=123456789012345
META_VERIFY_TOKEN=كلمة-سر-من-عندك-123

ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxx

ALLOWED_NUMBERS=971500000000
OWNER_NUMBER=971500000000
```

> 🔑 `META_VERIFY_TOKEN` **تخترعه أنت** — أي نص عشوائي. ما تحصله في أي مكان.
> فقط لازم تكتب نفسه بالضبط في الخطوة 6.

### 5) شغّل الوكيل و ngrok

```bash
python -m app.doctor      # تأكد أن الاتصال بواتساب أخضر
./run.sh
```

في نافذة ثانية:
```bash
ngrok http 8000
```

### 6) اربط الـ webhook

في صفحة تطبيقك: **WhatsApp ← Configuration**، اضغط **Edit** جنب Webhook:

| الحقل | القيمة |
|---|---|
| **Callback URL** | `https://ab12-cd34.ngrok-free.app/webhook/whatsapp` |
| **Verify token** | نفس `META_VERIFY_TOKEN` من `.env` بالضبط |

اضغط **Verify and save**.

> ✅ لازم الوكيل يكون **شغّالاً** لحظة الضغط، وإلا يفشل التحقق.
> إذا ظهر خطأ، راجع سجل الوكيل — بيوضح السبب.

بعد النجاح، في جدول **Webhook fields** اضغط **Manage** وفعّل **messages** ✔️

### 7) جرّب

من جوالك أرسل **`بدء`** للرقم التجريبي الظاهر في صفحة API Setup.

## 🔴 خطوتان لا تنساهما للاستخدام الدائم

### أ) توكن دائم (التوكن المؤقت يموت بعد 24 ساعة)

1. [business.facebook.com](https://business.facebook.com) ← **Business Settings**
2. **Users ← System Users ← Add** ← اسم أي شي، الدور **Admin**
3. **Add Assets** ← اختر تطبيقك ← صلاحية **Full control**
4. **Generate New Token** ← اختر التطبيق ← فعّل صلاحيتي:
   - `whatsapp_business_messaging`
   - `whatsapp_business_management`
5. اختر **Never expires** ← انسخ التوكن وضعه في `META_ACCESS_TOKEN`

### ب) قالب معتمد (عشان توصلك التنبيهات)

واتساب **يمنع** إرسال رسائل حرة بعد 24 ساعة من آخر رسالة منك. الوكيل يتحول
تلقائياً لقالب معتمد، لكن لازم تعتمده أولاً:

1. [business.facebook.com/wa/manage/message-templates](https://business.facebook.com/wa/manage/message-templates)
2. **Create Template**
   - **Category**: `Utility`
   - **Name**: `market_alert` ← نفس الاسم بالضبط
   - **Language**: العربية
3. في **Body** اكتب:
   ```
   🔔 تنبيه من المستشار الاقتصادي:

   {{1}}
   ```
4. في **Sample** اكتب أي مثال، ثم **Submit**

الموافقة تجي خلال دقائق إلى ساعات.

> بدون هذا القالب، التنبيهات ما توصلك إلا إذا كلمت الوكيل خلال آخر 24 ساعة.

## 🖥️ للتشغيل الدائم (بدون لابتوبك)

`ngrok` ينفع للتجربة فقط. للاستخدام الحقيقي استأجر خادماً رخيصاً
(DigitalOcean أو Hetzner بـ 5 دولار شهرياً) وشغّل:

```bash
git clone <رابط-المستودع> && cd mohammed-
cp .env.example .env    # عبّي المفاتيح
docker compose up -d
```

ثم وجّه نطاقك للخادم واستخدم `https://نطاقك/webhook/whatsapp` كـ Callback URL.

> شهادة HTTPS **إلزامية** — واتساب يرفض `http`. استخدم Caddy أو Nginx مع
> Let's Encrypt (مجاني).

## 🔧 حل المشاكل

| المشكلة | السبب الغالب | الحل |
|---|---|---|
| **التحقق من الـ webhook فشل** | الوكيل مو شغّال، أو التوكن مختلف | شغّل `./run.sh` أولاً، وتأكد أن `META_VERIFY_TOKEN` متطابق حرفياً |
| **أرسل ولا يرد** | الرابط ناقص `/webhook/whatsapp` | راجع الرابط في إعدادات واتساب |
| **أرسل ولا يرد (Meta)** | رقمك غير مضاف في قائمة المستلمين | صفحة API Setup ← **Manage phone number list** |
| **«هذا الرقم غير مصرّح له»** | رقمك مو في `ALLOWED_NUMBERS` | أضفه بالصيغة الدولية بدون `+` |
| **يرد لكن بدون أسعار** | مصدر البيانات محجوب على شبكتك | جرّب `python -m app.doctor` ← قسم «بيانات السوق» |
| **توقف فجأة بعد يوم** | توكن Meta المؤقت انتهى | أنشئ توكناً دائماً (القسم أ فوق) |
| **التنبيهات ما توصل** | خارج نافذة الـ 24 ساعة بدون قالب | اعتمد قالب `market_alert` (القسم ب فوق) |
| **Twilio وقف بعد 3 أيام** | صندوق التجربة ينتهي كل 72 ساعة | أعد إرسال كلمة `join` |

### تشخيص سريع

```bash
# 1) فحص شامل للإعدادات
python -m app.doctor

# 2) هل الوكيل يرد أصلاً؟ (بدون واتساب)
curl -X POST localhost:8000/admin/test-message \
  -H 'content-type: application/json' \
  -d '{"phone":"971500000000","text":"وش رايك في الذهب؟"}'

# 3) هل الخادم حي؟
curl localhost:8000/health

# 4) راقب السجل وأنت ترسل رسالة من جوالك
./run.sh --log-level debug
```
